Scaling

      

        
        
      

      
Used whenever Ainvil resizes an image behind the scenes: the input image to the generation size (img2img and inpainting), and Focused inpainting's context window and paste-back. When an image gets bigger and an upscale model is chosen, the model upscales it first and the resize method then brings it to the exact size. Shrinking always uses the resize method alone.

Custom Workflows (Extras)

      

        
        
        
      

      
Custom workflows run in the Extras tab. Each parameter has a name, a type and the workflow input(s) it sets. An image parameter uploads the images added in Extras (several images = one run each). %input% in a filename prefix is the input image's name.

      

      

    

  









  

    

      
Server History

      
      
      
      
    

    
Recent prompts from every client of this ComfyUI server, newest first. The server keeps them in memory, so they're gone after a restart.
